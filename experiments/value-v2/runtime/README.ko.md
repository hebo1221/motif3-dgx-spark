# 양자화 배치 수치 일관성 검사

큰 모델 없이 Q8_0 행렬의 단일 열·배치 연산을 비교하는 검사기와, 실제 모델에 고정한 토큰을 다시 입력하는 검사기를 공개한다. 소스와 단계별 재현 방법은 [영문 설명](README.md)에 있다.

GB10에서 세 행렬 모양과 2·4열을 시험했을 때 작은 선택형 수정안은 147,456개 값 모두를 단일 열 기준과 비트 단위로 일치시켰다. 8열은 지원 범위 밖으로 남겼다. 기본 출력과 기존 라이브러리 복구 출력은 9개 조합에서 유지됐다.

수정안은 기존 배치 경로보다 약 1.92–5.18배 오래 걸렸다. 빠른 최적화가 같은 계산 결과를 유지하는지 확인하는 단순한 기준 구현이다. 일반 성능 향상용 기본 패치로 권하지 않는다.

별도 Qwen3-8B Q8_0 고정 토큰 시험에서는 144개 위치의 내부 logits 차이를 관찰했지만 2·4·8 묶음마다 최대값 토큰 차이는 0건이었다. 이 시험은 기존 런타임·기존 Motif 런타임·기존 런타임 복구를 비교했으며, 새 작은 패치가 전체 모델의 품질이나 speculative decoding을 고친 시험이 아니다.

공개 기준 커밋은 `cc3f13b3f172978d7b3c215780d4cc98bb0e1c80`이다. 작은 Q8 패치와 기존 큰 MTP 패치는 별도 대안이므로 겹쳐 적용하지 않는다. 공개된 소스에 패치가 적용되고 측정한 두 CUDA 소스 해시와 같아지는지 확인했다. 측정 당시에는 기존 객체를 재사용해 CUDA 소스 하나를 다시 빌드했다. 새 전체 CMake 빌드, 다른 GPU와 모든 텐서 모양은 검증하지 않았다.
