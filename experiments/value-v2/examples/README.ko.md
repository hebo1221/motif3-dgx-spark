# 실제 답변과 원문

모델이 만든 답변을 수정하지 않고 원문 구절과 함께 표시했다. 아래 검토 의견은 별도다.

- [Motif: 토큰 일치의 의미](motif-parity.md): BF16 품질 보존과 실행 일치를 올바르게 구분했다. 본문의 한 행 번호는 잘못 적었지만 구조화된 원문에는 올바른 근거도 포함된다.
- [Qwen: 인용이 있어도 잘못 해석한 답](qwen-parity-error.md): 두 모델 간 출력 일치로 잘못 설명했다. 실제로는 같은 IQ2 런타임의 가속 전후 비교다.
- [Motif: 대상 혼동 수정 확인](motif-source-target-fixed.md): HELDOUT-020의 K39271을 해당 문서에서 읽었다. 이미 본 실패의 재검사다.
- [Motif: 문장은 완결됐지만 사실이 틀린 답](motif-complete-but-wrong.md): BF16 원본 크기는 629.69 GB이며, 89.72 GB는 IQ2다. 원본 시작 실패가 어느 문서에 기록됐는지도 잘못 귀속했다. 이 답변을 승인하지 않는다.

검토 목적은 인용의 존재와 내용의 정확성을 구분하는 것이다. 이 예제들을 신뢰도 보증이나 새로운 평가 표본으로 사용하지 않는다.
