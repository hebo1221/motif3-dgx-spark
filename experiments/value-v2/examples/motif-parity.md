# 검토할 답변

motif-runtime과 motif-agent-current를 함께 검토한 결과, 5,560개 토큰 일치는 BF16 원본과 IQ2의 품질 일치를 뜻하지 않습니다. motif-runtime L5에 따르면 11개 요청의 출력 토큰 5,560개가 가속 꺼짐·켜짐·복구 실행에서 모두 일치한 것은 '통합 추론과 지정 성능 기준 PASS'이며, 품질 개선 미검증입니다. 비교 대상은 '같은 통합 런타임의 target-only'이며, 토크나이저 패치만 넣은 동일 기반 대조본과 비교 시 두 답변의 표현이 달라 완전 동일 출력이나 기존 품질 점수 승계를 주장하지 않습니다. motif-agent-current L5에서도 Qwen 비교는 고정밀 대조를 대신하지 않으며, IQ2가 원본 품질을 보존한다거나 개선했다고 말할 수 없다고 명시합니다. 따라서 5,560개 토큰 일치는 동일 런타임 내 실행 재현성만 확인한 것이며, BF16 원본과 IQ2의 품질 일치를 의미하지 않습니다.

## 확인한 원문

### motif-runtime · 5–5행

> **공개 direct IQ2 모델에 최종 토크나이저와 MTP를 통합했고, draft 1을 권장하는 실험용 실행 구성을 만들었다.** 11개 요청의 출력 토큰 5,560개가 가속 꺼짐·켜짐·복구 실행에서 모두 일치했다.

원문 SHA-256: `19959a2a6263e5f564bb74d7c380071f92530aacd7de1f876729d5c4e457f50a`

### motif-runtime · 60–60행

> **MTP의 비교 기준은 같은 통합 런타임의 target-only이다.** 토크나이저 패치만 넣은 동일 기반 대조본과 비교하면 입력은 같지만 네 개발 요청 중 두 답변의 표현이 달랐다. 각각 자기 전·후 실행은 재현됐다. CUDA 변경은 일반 한 토큰 생성 경로에도 영향을 줄 수 있으므로, 기존 런타임과의 완전 동일 출력이나 기존 품질 점수의 승계를 주장하지 않는다.

원문 SHA-256: `19959a2a6263e5f564bb74d7c380071f92530aacd7de1f876729d5c4e457f50a`

### motif-agent-current · 5–5행

> **네이티브 도구 호출 문제를 수정하고, 로컬 문서를 검색·열람·계산해 인용과 함께 답하는 실행기를 만들었다. 이 문서 업무의 기본 모델은 Qwen3-8B Q8_0으로 정했다.** 같은 고정 100문항에서 Motif IQ2는 99건, Qwen은 100건을 맞혔고, Qwen의 전체 처리 시간은 약 3.3배 짧았다.

원문 SHA-256: `57a8e523f182a0b672c3a558b15058d66e82436eb112f4de7fef66cf822bcce8`

### motif-agent-current · 50–52행

> 기존 629.69 GB BF16 원본을 mmap과 CPU MoE offload로 시작하는 제한 검사를 수행했다. **300초 안에 서버가 준비되지 않았고 추론 요청은 0건**이었다. 해당 프로세스는 종료했다. 이 결과는 이번 시간 한도에서 시작하지 못했다는 뜻이며, 메모리 부족이 입증됐다거나 원본 실행이 불가능하다는 뜻은 아니다.
> 
> 따라서 이번 작업으로 IQ2가 원본 품질을 보존한다거나 품질이 개선됐다고 말할 수 없다. Qwen 비교는 이 고정밀 대조를 대신하지 않는다. 이전에 관찰한 범용 코드 생성의 반복 문제도 이번 문서 도구 프로필로 해결됐다고 주장하지 않는다. [BF16 제한 검사](evidence/bf16-canary-v1/receipt.json).
